# T4 V3 — Transitions hybrides cinématiques

La V3 répond aux deux corrections successives du propriétaire :

- la V1 était trop exagérée parce que les effets interrompaient constamment les rushes ;
- la V2 était trop basique parce que les fondus ne marquaient pas suffisamment le changement ;
- la V3 crée donc **trois moments impressionnants uniquement autour des trois coupes**.

## Signatures choisies

| Raccord | Fenêtre | Durée | Signature |
|---|---:|---:|---|
| Bienvenue → Service | images 176–183 | 8 images / 267 ms | whip-pan horizontal rapide |
| Service → Dégustation | images 416–423 | 8 images / 267 ms | zoom traversant le plat |
| Dégustation → Ambiance | images 626–633 | 8 images / 267 ms | whip-zoom d’ouverture |

Chaque fenêtre commence quatre images avant la coupe et se termine quatre images après. La première image reste identique au plan sortant et la dernière retombe exactement sur le plan entrant.

## Équilibre

- 24 images de transition sur 900 ;
- 876 images naturelles plein écran ;
- **97,33 %** du montage sans effet de transition ;
- aucune transition au milieu d’une fenêtre stable ;
- trois dernières secondes de S4 sans effet.

## Interdictions maintenues

- aucune mosaïque ni grille ;
- aucun panneau ou bloc rectangulaire ;
- aucun glitch ou décalage RVB ;
- aucun flash blanc ou séparateur coloré ;
- aucune vibration persistante ;
- aucun texte et aucune piste audio dans le candidat silencieux.
